# Security policy

Report vulnerabilities privately to the repository owner; do not open public
issues for active exploits. Include affected version, reproduction, and impact.

Supported: latest `v0.x` release. PRISM is test-mode financial infrastructure —
never run with live credentials outside audited production deployments with
rotated secrets, TLS, tenant isolation review, and off-site encrypted backups.
See `docs/security/threat-model.md` and `docs/security/data-retention.md`.
